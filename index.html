About this codebook
PCNN variable dictionary — researcher view

The PCNN Codebook is the variable dictionary for the Post-COVID Network Netherlands, a national collaborative research initiative funded by ZonMw. It documents the validated questionnaires used across PCNN sub-studies (PROMIS-29, DSQ family, EQ-5D-5L, COMPASS-31, Pain DETECT, SF-36, and others) and supports FAIR (Findable, Accessible, Interoperable, Reusable) data alignment across the network.

This is the researcher view of the codebook — read-only, with 9 curated fields. Use the "Suggest" button on any row to propose a change to the administrator.

🔒 Copyrighted questionnaires (PROMIS, EQ-5D, and others) are shown as placeholders. Contact the codebook owner for access to the full item list.

Built by Hajar Hasannejadasl — Maastricht University Medical Centre+ (MUMC+). Developed within the Post-COVID Network Netherlands (PCNN), funded by ZonMw.

What each role can do

adminEverything: edits, approves or rejects suggestions, publishes or hides instruments, deletes and restores, imports, users and roles, field access, backups and releases. Sees and assigns all tasks.
editorEdits variables and instrument descriptions directly; changes to fields set to “needs approval” become suggestions. Reads the Log. Sees unpublished instruments, and the tasks assigned to them.
ontology_engineerEdits only the fields granted under Manage fields (for example the FAIR codes); other changes become suggestions, followed under My suggestions. Sees unpublished instruments, and the tasks assigned to them.
researcherReads published instruments in the researcher view; restricted instruments (for example PROMIS) show a 🔒 row instead of the questions. Can suggest changes.

Which fields each role may edit is set per field under Admin → Manage fields.

Quality

Duplicates, missing values, answer scales, FAIR status and automatic checks — with the list behind every number.

Dashboard

Tasks

Work to do on the codebook, per work group. Admins see, add and assign all tasks; everyone else sees the tasks assigned to them and sets their status.

Imports

Every batch of variables added together (Excel or Castor XML). Undo puts a whole batch in the Trash — nothing is lost, and you can restore it here or in Trash.

Trash

Soft-deleted variables. Restore brings them back into the codebook.
